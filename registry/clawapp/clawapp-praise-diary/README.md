# 夸夸日记

把亲子相处中值得被看见的努力收进“星星罐”。支持文字、录音、图片和短视频，适合父母和孩子随时记录那些温暖、勇敢、独立与成长的瞬间。

## 三个页面

- **星光**：看近期夸夸，用文字、语音、图片或视频收下一颗星。
- **时光**：按月历、图库和关键词回看家庭记忆。
- **家人**：查看一起记录的家庭成员与星光统计。

## 私有存储

应用默认不对外开放。日记记录保存在应用自己的实体目录，媒体保存在应用自己的 `files/media/`；单项上限 32 MiB。升级应用会保留日记和媒体，只有卸载才删除整套应用数据。

这是独立 ClawApp，不创建 `.llm`，也不会进入智能文件夹列表。分发物是标准 `.clawapp` 包，可直接从商店安装或升级。
