# 夸夸日记

把亲子相处中值得被看见的努力收进“星星罐”。支持文字、录音、图片和短视频，适合父母和孩子随时记录那些温暖、勇敢、独立与成长的瞬间。

## 三个页面

- **星光**：看近期夸夸，用文字、语音、图片或视频收下一颗星。
- **时光**：按月历、分类和关键词回看家庭记忆，可打开、编辑、分享或删除日记。
- **家人**：在应用内创建和切换家庭、管理成员、生成本地家庭口令，并查看星光统计。

## 私有存储与对外入口

日记、家庭和成员记录保存在应用自己的实体目录，媒体保存在应用自己的 `files/media/`；单项上限 32 MiB。家庭逻辑完全由应用自己的 JavaScript 和实体实现，不依赖“家庭中台”或外部连接器。

应用安装后即提供公开链接。亲友打开链接只能填写一张「送一颗夸夸星」表单，不能读取家庭、成员、历史或媒体；写入动作由服务端校验并限流。升级应用会保留日记和媒体，只有卸载才删除整套应用数据。

这是独立的手机版 ClawApp，不创建 `.llm`，也不会进入智能文件夹列表。分发物是标准 `.clawapp` 包，可直接从商店安装或升级。
